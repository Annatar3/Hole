Hole

P2P service access over HyperDHT — no port forwarding, no VPN, no accounts.

v0.4.3 Linux macOS Windows Node ≥18
$ curl -fsSL hole.onl/get | sh

Installs to ~/.local/bin/hole by default. Override with INSTALL_DIR=/usr/local/bin curl -fsSL hole.onl/get | sh.
Or grab a binary directly from the releases page.

PS> irm hole.onl/get.ps1 | iex

Installs to %LOCALAPPDATA%\hole\hole.exe and adds it to your user PATH.
Or download hole-win-x64.exe from the releases page.

$ git clone https://github.com/Annatar3/Hole && cd Hole $ npm install && npm link $ hole help

Requires Node ≥ 18. Use Node 22 (.nvmrc) for building release binaries.

What you get

hole up

Announce this machine's services on the DHT. SSH forward is always included; add RDP, HTTP, or any TCP service with --forward.

hole ssh

One-command interactive SSH through the tunnel. No port forwarding or VPN needed.

hole tunnel

Expose any TCP service (RDP, HTTP, DB…) as a local port.

hole proxy

Local SOCKS5 proxy that reaches any service on a remote network on demand — one tunnel instead of a forward per port.

hole exec

Run a command on a remote host and get the output. No persistent session needed.

hole copy

Transfer files to or from a remote host over the P2P tunnel.

hole share

Send a file to anyone with a short one-time code — no pre-registration, no SSH keys.

hole invite

Pair a new device with a short code. No need to copy a 64-character public key.

hole relay

Self-hosted UDP relay for CGNAT and mobile networks. Deploy on any VPS.

hole dashboard

Browser fleet UI — terminals, tunnels, exec, file browser, ACLs, audit log.

Examples

Pair and SSH into a remote machine
# on the remote machine hole invite --name my-server # Invite code: blue-river-cedar-4821 # on your laptop hole accept blue-river-cedar-4821 hole ssh my-server
Send a file to anyone — no setup
# sender hole share report.pdf # Share code: amber-stone-cedar-7823 # receiver (any machine) hole receive amber-stone-cedar-7823 # Saved to report.pdf
Reach a remote network's internal services
# machine with access to the internal services hole up --name my-net --proxy # your laptop hole proxy my-net # SOCKS5 : 127.0.0.1:1080 curl --socks5-hostname 127.0.0.1:1080 http://internal-dashboard.lan
Expose multiple services + relay (CGNAT)
# VPS — open UDP 49737 in firewall first hole relay --host 203.0.113.10 # remote machine hole up --name my-pc --relay 203.0.113.10:49737 \ --forward rdp:3389 --forward web:3000 # laptop hole tunnel my-pc rdp # RDP on localhost:<port> hole tunnel my-pc web # browser on localhost:<port>
